Burpsuite Remote 把手机变成 Burp Suite 的遥控器，让你离开电脑后也能继续测试。

真正干活的是桌面端扩展程序。Android 应用只负责发送指令和渲染结果，不在手机上重新实现任何功能，也不会把数据发给任何第三方服务。

你可以做什么

• 实时代理历史 —— Burp 看到的每一个请求都会在毫秒内到达手机，带上方法、URL、状态码和时间戳。点开任意一条就能查看完整的请求与响应。

• 随时随地做拦截决策 —— Burp 拦截到请求时会出现在手机上。转发、丢弃，或者改完再转发，由 Burp 执行你的决定。

• 手机上的 Repeater —— 一键把任意历史记录送进 Repeater，调整请求、发起执行、读取响应。状态码、耗时和响应体会回到应用里。

• 桌面小组件与锁屏小组件 —— 一个连接状态小组件，一个实时统计小组件，显示目标主机、实时请求数、拦截数和已保存数。小组件读取的是缓存快照，不会常驻后台服务。

• 分享与导出 —— 把归档流量导出为脱敏副本，存储的原始数据保持逐字节不变。

• 8 种主题与液态玻璃 —— 3 种明暗模式（跟随系统、浅色、深色）与 8 种配色组合。底部导航栏使用实时模糊，浅色与深色参数分别调校。

• 5 种语言 —— 英文、简体中文、德文、日文和蒙古文。默认跟随设备语言，也可以按应用单独覆盖。

工作原理

1. 在你电脑上的 Burp Suite 里加载 Burp Remote 扩展。
2. 在 Burp 里打开 Burp Remote 标签页，显示配对二维码。
3. 用应用扫码。配对码一次性有效，五分钟后过期。
4. 两台设备必须在同一个局域网内。

连接采用事件溯源：Burp 的每一次变更都会通过 WebSocket 推送到应用并投影成状态，所以手机不需要轮询，历史记录也不需要手动刷新。

系统要求

• 已在你电脑的 Burp Suite（Community 或 Professional，2025.x 及以上）中加载 Burp Remote 扩展。没有扩展，应用本身什么也做不了。
• Android 8.0（API 26）或更高版本
• 两台设备处于同一个局域网

安全与隐私

本应用是为可信局域网设计的。手机与 Burp 之间的流量是明文 HTTP，没有 TLS，也刻意不打算暴露到公网。请不要把扩展的端口转发到公网。

每条连接都带设备身份，未注册的设备会被拒绝。控制指令按设备限流，并按操作 ID 去重，因此重试会返回第一次的结果，而不会执行两次。每条指令都会写入审计日志，记录设备、类型、操作 ID 和结果。归档的原始数据不会被改写，脱敏只作用于导出的副本。

本应用不含分析 SDK、广告 SDK，也没有崩溃上报服务。二维码配对完全在设备本地完成。应用只与你自己的 Burp 实例通信，不连接其他任何地方。开发者不收集任何数据。

开源

Burpsuite Remote 基于 MIT 许可证免费开源。完整源码、扩展和文档都在 GitHub 上。欢迎提交 Issue 和 Pull Request。

请注意，桌面端扩展需要单独构建或下载；只有应用本身无法代理任何流量。
